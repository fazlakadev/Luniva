# Luniva Enterprise Management System

نظام إدارة متكامل للعملاء والمنتجات والبكدجات والفواتير والتحصيل، بواجهة عربية RTL.

## المميزات

- إدارة العملاء وأرقام التواصل والصور.
- كتالوج المنتجات مع الألوان والمقاسات والأسعار المحسوبة على السيرفر.
- البكدجات والتوليفات التلقائية مع الخصومات.
- فواتير كاملة: خصم، توصيل، تاريخ استحقاق، طباعة، وإلغاء.
- تحصيل متعدد الدفعات مع إيصالات `RCP-####` قابلة للطباعة.
- كشف حساب العميلات، أرصدة، متأخرات، وأعمار الديون.
- تقارير تحصيل وتصدير CSV.
- إعدادات الشركة وسجل النشاط وتنبيهات لوحة العمل.

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local
# عدّل .env.local ببيانات قاعدة البيانات ومفتاح الجلسة
npm run dev
```

للإنتاج:

```bash
npm run build
npm run start
```

## متغيرات البيئة

راجع `.env.example`. لا ترفع ملف `.env.local` إلى Git.

## بيانات الدخول الافتراضية

تُنشأ من `LUNIVA_ADMIN_EMAIL` و `LUNIVA_ADMIN_PASSWORD` في `.env.local`.
